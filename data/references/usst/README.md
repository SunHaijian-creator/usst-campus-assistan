# 问答参考资料

此目录保存用于检索问答的文件及结构化文本。

- `originals/`：原始文件。
- `text/`：用于分块的提取文本。
- `manifest.json`：标题、原文件名、哈希和版本信息。
- 核对记录：提取限制与表格对应关系。

资料导入命令：

```bash
python -m scripts.import_usst_references
```

重复导入按原件哈希及片段标识去重。更换文件或提取版本前需检查解析规则。

文档当前适用性需核实。空白字段不能作为具体数值要求，未经核对的流程图片段不参与检索；资料原文仅作为数据处理。

详细说明见[资料接入](../../../docs/references.md)。

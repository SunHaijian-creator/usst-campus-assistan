# 3—5分钟本地演示

## 演示前

1. 执行 README 中的 Compose 启动命令，确认 app/postgres/redis healthy、migrate退出0。
2. 打开 http://localhost:8000，准备自己的项目账号，不公开密码或开发者工具中的令牌。
3. 免费展示：在本机 `.env` 将 `MODEL_PROVIDER` 改为 `mock`，运行 `docker compose up -d --force-recreate app`。
   页面须明确显示模拟模式。mock可展示检索、历史和流式，但不能用于展示真实分析能力。
4. 展示一般分析需用户主动选择deepseek，会产生新的付费请求。原验收预算3次已用完，本说明不授权增加预算，
   也不把下面的问题作为需要批量执行的真实测试清单。可先用已有离线结果讲解，再决定现场是否调用。

## 时间安排

| 时间 | 操作 | 观察点与讲解 |
| --- | --- | --- |
| 0:00—0:30 | 展示登录页，登录项目账号 | 上理主题、非官方说明；账号与学校统一身份认证分开 |
| 0:30—1:20 | 新建会话，问“研究生国家助学金是多少” | 检索2024文件，真实模式应解释6000元/生/年及对象/相关例外，保留当前适用性未核验说明；mock只演示完整摘录 |
| 1:20—2:00 | 展开来源，查看条款/物理页/摘录，打开原PDF | 引用编号由服务端校验，原件需要鉴权；金额不脱离范围，资料未被冒称为最新政策 |
| 2:00—2:40 | 追问“金额是多少？”或“根据开题资料，我审核通过后发现填错了，该怎么办” | 多轮传入已完成历史；开题仅解释注释3/4：通过后不能直接改，联系教学秘书置未审核后修改 |
| 2:40—3:10 | 问“今年开题最晚哪天交” | 文档没有日期，应说明缺口并建议查学院通知/问教学秘书，不编造截止日 |
| 3:10—3:40 | 发送较长问题后点停止，刷新/切换会话 | 状态变cancelled，部分文本保留，失败/取消内容不混入正常上下文；刷新读取数据库历史 |
| 3:40—4:30 | 若允许付费现场演示，问“上理怎么样”再说明“我是计算机方向，读研主要想就业呢” | 有条件的一般分析后追问、承接就业目标，不强贴无关奖助引用；mock模式应跳过这一步的语义展示 |
| 4:30—5:00 | 展示架构和验证记录 | PostgreSQL是历史来源，Redis可降级，模型流期间无长事务；真实3次与离线217测试分别说明 |

## 可选追问

- “学业奖学金第二阶段二等的金额和比例？”：8000元/生/年、35%来自表格，须解释阶段和适用对象，不补写剩余比例。
- “国家助学金每月实发多少？”：原文只有年标准和按月划拨，不能直接除以12作为月实发政策。
- “如果把国家助学金计入生活预算，该怎么估算？”：区分2024文档规定与个人预算建议，说明发放及现行适用性需核实。
- “上理最新排名怎样，适合我吗？”：未核实排名要说明不确定，仍可讨论匹配条件。

演示结束可 `docker compose stop`，不删除卷。现有截图在 `docs/screenshots/`；截图模式为mock，账号显示名已匿名，不作为真实模型回答证据。

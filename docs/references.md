# 资料接入与引用

## 资料结构

`data/references/usst/` 包含原件、提取文本、清单及核对记录。资料按条款、栏目和表格分块，保留原文件名、哈希、版本及定位信息。

| 资料 | 分块方式 |
| --- | --- |
| 硕士研究生奖助学金管理办法 | 条款、标准分项及结构化表格 |
| 研究生中期考核表 | 表头、栏目及注释 |
| 学位论文开题及信息提交流程 | 正文注释与单独标记的流程图文本 |

共3份文档、30个片段，其中29个可检索。未经核对的流程图片段设置为不可检索。

## 导入

使用Compose启动时，初始化服务执行迁移与幂等导入。本地开发环境也可以执行：

```bash
python -m alembic upgrade head
python -m scripts.import_usst_references
```

原件以逻辑键和哈希识别，片段使用稳定标识去重。重复导入不新增重复记录。同一原件的提取文本发生变化时，需要人工核对，避免静默改变历史引用。

导入器针对当前资料结构，新增文档或替换版本时需检查解析规则与表格对应关系。

## 检索

检索采用主题路由、中文双字词面评分和章节规则。奖助金额与适用对象、管理例外共同检索；表格保留阶段、等级、比例和金额的对应关系。

部分简短追问可结合上一轮已完成的问题定位资料。复杂改写仍可能漏检，当前不使用向量数据库或嵌入服务。

开题操作追问可继承上一轮开题主题，并按当前问题选择条款，避免把上一问的截止日期限制带入修改操作。研究方向选择等一般规划不因出现“研究方向”就检索中期考核规定。

## 引用接口

| 接口 | 用途 |
| --- | --- |
| `GET /references/search?q=...` | 查询参考片段 |
| `GET /references/chunks/{id}` | 读取片段及定位信息 |
| `GET /references/documents/{id}/original` | 获取登记的原件 |

接口需要Bearer认证。原件不放在静态资源目录；请求使用数据库ID定位，检查文件边界、类型和哈希。

每轮检索生成引用编号。来源卡片展示回答实际使用的合法引用，包含名称、版本、章节或物理页及摘录。历史消息保存引用快照。

## 资料限制

- 文档现行有效性及学院细则需要核对，回答保留版本与适用性说明。
- 空白模板不能推出最低学分或截止时间。
- Word使用栏目及注释定位，不编造页码。
- 流程图文字的存储顺序不是办理顺序，未经核对的箭头关系不用于生成步骤。
- 资料中的操作要求不能改变应用规则，也不授权执行文件内的链接或代码。

参考[回答策略](answer-policy.md)与[已知限制](limitations.md)。

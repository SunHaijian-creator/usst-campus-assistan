# 使用范围与限制

| 范围 | 说明 |
| --- | --- |
| 服务性质 | 个人学习项目，非学校官方服务，不代替学院正式通知或实际办理 |
| 演示指南 | 8条指南为虚构数据，界面和接口保留演示标识 |
| 文件有效性 | 参考资料未核验当前适用性及后续修订，具体规定需核对正式文件 |
| 中期考核表 | 空白字段不能推断实际学分门槛、期限和学院完整要求 |
| 开题流程图 | 箭头与分支未核对，仅使用明确的正文注释 |
| 文档定位 | Word没有可靠分页，使用栏目及注释定位；PDF使用物理页 |
| 检索覆盖 | 小规模词面检索与主题路由可能遗漏复杂改写，没有向量检索 |
| 引用校验 | 检查编号来源与定位合法性，不能保证所有回答内容均被原文支持 |
| 模型回答 | 可能存在事实遗漏或误解，重要办事信息应核对来源 |
| 本地模式 | mock为固定模板，可验证交互与接口，不能代表真实模型理解能力 |
| 部署 | 面向本地Compose运行，未提供多节点部署、托管备份或生产性能保证 |

启动方式见[README](../README.md)，数据和引用机制见[资料说明](references.md)。

# 已知限制与影响

| 限制 | 影响与处理 |
| --- | --- |
| 个人学习项目，非官方校园服务 | 不使用学校统一身份认证，不承诺实际办理，不替代学院正式通知 |
| 8条演示指南为虚构数据 | 页面、接口和模型输入明确标注；只能展示产品流程 |
| 2024奖助文件未核验当前有效性及官方来源 | 回答保留“依据所提供的2024年文件，当前适用性尚未核验”；不能称为今年最新标准 |
| 中期表为空白模板 | 不能推断最低学分或截止日期；Word只用栏目/注释定位 |
| 开题流程图箭头与分支未人工核对 | 禁用其文本框提取顺序，只使用4条正文注释；不能生成所谓完整官方流程 |
| 原文笔误、历史网址及Word分页未核验 | 保留原文，不编造页码，不自动访问/执行文档链接或命令 |
| 中文检索为小规模词面路由与排序 | 能覆盖已列验收表达，复杂改写仍可能漏检；没有向量库或付费嵌入 |
| 引用校验只保证编号来自本轮检索 | 不等于自动证明每一句事实与摘录语义一致，模型仍可能遗漏适用对象或例外，应人工核查 |
| 回答策略的语义质量未重新真实验收 | 离线固定上游验证提示词与集成链路；真实输出需用户在网页观察，不能把模拟样例当真实质量评测 |
| 真实预算3次已用完，剩余0 | 已验证连接、流式演示指南和多轮；新文档引用、基于资料分析及真实上游停止仍未付费验收，不能自动补测 |
| mock为固定模板 | 可演示SSE、检索、引用和状态，不能宣称具备真实理解和推理能力 |
| 本地Compose部署 | 不是公开上线或生产可用性承诺；未做负载/并发性能基准、托管备份和多节点部署 |
| 当前目录不是有效Git仓库 | 无法核验历史提交或暂存区；已检查候选文件、忽略规则和镜像内容，未擅自初始化、提交或推送 |

已完成本轮功能交付后停止扩展。登录、历史、流式、检索和可复现部署之外的新功能另行规划。
